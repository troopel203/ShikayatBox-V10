# 🏛️ ShikayatBox

### A Smarter Way to Report, Track & Resolve Civic Issues

ShikayatBox is a citizen-focused grievance reporting platform designed to make reporting local civic problems simpler, faster, and more transparent.

Instead of struggling with complicated complaint systems, citizens can use ShikayatBox to raise issues and help bring attention to problems in their communities.

---

## 🚀 Why ShikayatBox?

Civic problems such as:

- 🛣️ Damaged roads and potholes
- 💡 Broken streetlights
- 🗑️ Garbage and waste issues
- 🚰 Water supply problems
- 🚧 Damaged public infrastructure
- 🌳 Public-space and cleanliness issues

often take time to reach the right authority.

**ShikayatBox aims to bridge this gap by providing a simple digital interface for citizens to report problems.**

---

## ✨ Key Features

### 📝 Easy Complaint Reporting
A simple interface that allows citizens to describe and submit civic issues.

### 🏷️ Smart Issue Categorization
Complaints can be organized into relevant categories, making them easier to understand and process.

### 🤖 ML-Based Text Classification
The project includes a text classification model that can help categorize complaint descriptions automatically.

### 📊 Transparent Complaint Flow
Designed around a clear complaint lifecycle so users can understand what happens after reporting an issue.

### 🌐 Citizen-Friendly Interface
A clean and accessible interface designed for everyday users rather than technical users.

### 🖼️ Visual Communication
Relevant illustrations and visual elements help users understand the purpose and workflow of the platform quickly.
